# Сырые данные: размерности макроиндикаторов и переходы между ними

Открытый учебный и рабочий набор о том, **что на самом деле лежит в ряду макроданных и во что его можно
превратить**. Одно и то же число `1,2` может быть приростом цен за месяц, триллионами рублей с начала года
или долей безработных. Прежде чем строить график, считать долю в ВВП или переводить в доллары, нужно понять,
что именно опубликовано, — и только потом решать, какие преобразования осмысленны.

Всё работает на обычных файлах Excel в этой же папке — ни базы данных, ни настройки окружения не требуется.
Блокнот двуязычный: язык переключается одной строкой `LANG = "ru"` или `LANG = "en"`.

Третий репозиторий серии exit10: [сезонная корректировка](https://github.com/MikeMike13/SEASONAL) →
[выделение тренда](https://github.com/MikeMike13/TREND) → сырые данные.

Формат данных простой: один ряд — один файл `<ТИКЕР>.xlsx` с двумя столбцами, `Date` и `Value`, даты на
конец периода. Характеристики каждого ряда описываются в блокноте, в таблице `MANUAL_CHARACTERISTICS`.
Чтобы добавить свой ряд, положите файл в `RAW_DATA/` и допишите его характеристики.

## Установка

```bash
git clone https://github.com/MikeMike13/MACRO_RAW_DATA.git
cd MACRO_RAW_DATA
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
jupyter lab
```

Нужен Python 3.10 или новее. Откройте `raw_data_master_pgh.ipynb`, выберите язык в первой ячейке и
запустите блокнот целиком.

## С чего начать

Если хочется понять идею за десять минут — презентация `raw_data_ru.pdf`. Она начинается с четырёх цифр из
новостей, у которых четыре разные размерности, и показывает, что с каждой можно сделать дальше.

Если нужно разобраться — блокнот. Разделы 2–4 — теория и карта преобразований, раздел 5 — один график со
всеми метриками одного индикатора, раздел 6 — живые примеры, раздел 7 — шаблон для своего расчёта.

Если нужно посчитать свой ряд — функции `transform.py` принимают явные аргументы (частоту, тип ряда,
валюту) и работают с любым рядом, а не только с примерами из блокнота.

## Что важно знать до того, как применять

**Все преобразования идут через уровень.** Из накопленного с начала года ряда уровень восстанавливается
точно, из м/м и «к декабрю» — с точностью до множителя, из г/г и cmlt/cmlt — только при известном целом
базовом годе. От этого и зависит, что из ряда можно получить, а что нельзя.

**Поток складывают, запас берут на конец, цены усредняют.** Тот же принцип выбирает курс пересчёта:
поток — по среднему курсу, запас — по курсу на дату. Разница между ними доходит до 19%.

**«Посчитать можно» не значит «имеет смысл».** Ставку г/г в процентах, сумму запасов за год или
кубометры к ВВП в рублях модуль посчитает — функция `available()` подскажет, что результат ничего не
значит, но не запретит. Ответственность за смысл остаётся на аналитике.

**Характеристики рядов в `RAW_DATA/` описаны вручную.** Если берёте ряд из другого источника, проверьте
`mult` и `real_nominal`: ошибка в масштабе даёт расхождение в тысячу раз.
